## 上传前检查

- `wxapp/app.json` 页面配置正确
- 后端接口地址已切换到正式 HTTPS 域名
- 小程序后台已加入合法 request 域名
- 登录流程可用：`wx.login`
- 家长 / 学生 / 老师三个入口页面可打开
